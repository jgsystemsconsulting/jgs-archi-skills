jgs-archi-skills

Agent-guided ArchiMate viewpoint creation in Archi. One orchestrator skill plus twelve specialists drive the existing JGS Archi Bridge MCP. Archi is the only canvas.

You govern scope. The skills consume the MCP; they never copy ArchiMate tables and never patch the bridge.

§01 · What it is

A modelling run, not a diagram toy

You give the orchestrator a plain-language intent. It drafts a View Plan, grounds each viewpoint, and stops until you approve. Only then do layer specialists create or reuse elements in the live Archi model. MCP resources stay the ArchiMate reference. Skills never dump metamodel catalogs into chat.

§02 · Skill chain

Thirteen skills, one entrypoint

01

archi-orchestrator

User-invoked. Elicits intent and produces the View Plan. No mutations until you confirm.

02

elicit + viewpoint-select

Normalize fields. Trace each viewpoint to stakeholder, concern, purpose, and abstraction.

03

layer specialists

Motivation, capability/strategy, business, application, technology/physical, implementation/migration.

04

traceability

Explicit cross-layer traces. Gaps reported, not invented.

05

model-qa + layout

Compliance explain-and-propose. Archi-native layout only. No other canvas.

06

documentation

Structured rationale and a completion summary written into the model via MCP.

Index: SKILLS.md. Shared contract: CREATE_PATH.md.

§03 · Supported agents

Default ZCode, others first-class

ZCode (default)

Flat ~/.zcode/skills/<skill>/. Binding delivery form for this pack.

Native folders

Claude Code (namespaced jgs/), OpenClaw, Copilot CLI, Codex: copy the skill folder unchanged.

Transform

Gemini CLI as an extension. Cursor as project-local .mdc rules. See other-agents.md.

§04 · Install

Clone and install

# Python 3.10+, stdlib only. Archi + JGS Archi Bridge on loopback.
git clone https://github.com/jgsystemsconsulting/jgs-archi-skills
cd jgs-archi-skills
python install.py                 # ZCode, flat ~/.zcode/skills
python install.py --dry-run
python install.py --agent claude  # ~/.claude/skills/jgs/
python install.py --list-agents

Prerequisites: Archi with the JGS Archi Bridge plugin, MCP at http://127.0.0.1:18090/mcp. Usage guide: docs/skill-usage.md.

§05 · First run

Invoke the orchestrator

Restart the agent so it discovers the skills. Then call the orchestrator. Specialists are dispatched for you; do not invoke them yourself.

# load the orchestrator
/archi-orchestrator
# or pass intent in one shot
/archi-orchestrator invoice-to-cash capability map for finance and ops

It stops at a confirmation gate. Approve the View Plan before anything is written into Archi.
