# View Rationale: Capability Map

## Purpose
Show which five capabilities Meridian must strengthen and which resources support them, so investment maps to abilities rather than systems.

## Stakeholders and Concerns
COO wants an ability-level view before funding; IT Manager checks which capabilities lean on the integration platform.

## Viewpoint
Capability Map viewpoint (standard): Capability and Resource elements only.

## Questions Answered
Which capabilities exist, which resources back them, and which requirements each capability realizes?

## Assumptions
Resource-serving-capability is the correct support relation; validated live against the bridge relationship checker.

## Decisions
Each requirement is realized by at least one capability; the integration platform serves carrier management and analytics because both consume integrated feeds.

## Exclusions
Value streams and courses of action are excluded; the frozen scenario names none.

## Open Questions
Whether Customer Service Team should also serve Shipment Planning is unresolved; no process evidence in scenario.
