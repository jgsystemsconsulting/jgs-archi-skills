# Talk abstract

**Title:** Sign the view plan: agent-guided ArchiMate modelling that still writes into Archi

**Rooms:** Archi community meetup; Open Group Architecture / ArchiMate practitioner session; SATURN or ICSA industry track. 25–40 minutes plus demo.

**Abstract (about 180 words)**

Delivery teams ship weekly. Architecture views lag by sprints. ArchiMate already defined the viewpoints. Archi already holds the model. The method still lives in the architect's head: workshop, tacit viewpoint, a week of boxes, a review that finds the wrong cut, rationale in a slide deck.

Language-model tools make this worse when they emit PlantUML or a picture beside Archi. The system of record does not move. The architect is asked to bless a drawing.

This talk shows Skill-Orchestrated ArchiMate Modelling (SOAM): a skill pack that drives the JGS Archi Bridge inside Archi. You state the job in plain language. The orchestrator drafts a view plan. You approve or reject. Specialists write only after yes, and only the layers you named. Traceability, QA, layout, and documentation are stages. The ArchiMate language stays in MCP resources, not in the prompt.

Live (or recorded) Archi: open the mill CRM walk (OrderSight must not swallow MillOS; equipment on a node; five views on hatherley.html), then the Moorfield Range walk (RangePlan must not swallow GroundOS or AirStack; SysML off canvas). Optional install first-contact: stop invoice-to-cash at the view plan. Both paper walks are author-run frozen briefs in the we-repo, not client models. MIT. Archi 5.7+. No speedup chart. The claim is the gate.

**Speaker needs:** Archi with Bridge running, one throwaway model, agent session restarted so skills load.

**Takeaway slide:** Sign the plan. Archi stays the system of record. Delivery does not wait a sprint for a kitchen-sink drawing.
